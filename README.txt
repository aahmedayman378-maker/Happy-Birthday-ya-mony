HOW TO USE
==========
1. Double-click index.html to open the site in your browser.
2. To change the text, name, or messages: edit content.js (open it with Notepad or any text editor).
3. To add photos: put the image files in this same folder, then reference their filenames in content.js
   e.g. photos: ['photo1.jpg']
4. To change colors/fonts/spacing: edit style.css.
5. You normally don't need to touch script.js at all - that's just the animation logic.

Keep all 4 files (index.html, style.css, content.js, script.js) in the same folder,
along with any photos you add.
